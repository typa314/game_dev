# 任務 M3-4：四語系在地化（zh-TW / en / ja / zh-CN）擴充與 UI 文字長度驗證器

> **依據**：[`design/21_m3_content_live2d_and_dlc_plan.md`](../../design/21_m3_content_live2d_and_dlc_plan.md) Task M3-4、[`design/12_localization.md`](../../design/12_localization.md)、[`design/16_roadmap.md`](../../design/16_roadmap.md) M3、[`client/GEMINI_PROTOCOL.md`](../GEMINI_PROTOCOL.md)
> **目標**：新增日文（`ja`）與簡體中文（`zh-CN`）語系字典，使四大首發語系（`zh-TW`, `en`, `ja`, `zh-CN`）鍵值 100% 對齊；在 `LocalizationValidator` 新增 **UI 文字長度上限與富文字標籤成對檢查**，並在 `SettingsModalView` 支援四語系即時切換。

## 允許新增或修改的檔案（嚴禁修改範圍外檔案）
- `data/loc/zh-TW/strings.json`、`data/loc/en/strings.json`
- `data/loc/ja/strings.json`、`data/loc/zh-CN/strings.json`（新增並同步至 `StreamingAssets/Loc/`）
- `client/Assets/Game/Core/Localization/LocalizationValidator.cs`
- `client/Assets/Game/Unity/UI/SettingsModalView.cs`
- `client/Assets/Game/Tests/LocalizationTests.cs`
- `client/Assets/Game/Tests/EncounterAchievementSettingsViewTests.cs`

## 實作細項與介面規格
1. **四語系字典對齊 (`data/loc/{zh-TW,en,ja,zh-CN}/strings.json`)**：
   - 為新角色、第 3 章關卡、新成就補齊 `zh-TW` 與 `en` 鍵值，並完整建立 `ja`（日文）與 `zh-CN`（簡體中文）字典，確保四語系鍵值集合與 `{0}` 佔位符 100% 對齊。
2. **UI 文字長度與標籤驗證器 (`LocalizationValidator.cs`)**：
   - 新增 `ValidateUiLengthAndTags(ILocalizationService service, int maxUiButtonChars = 40, int maxGeneralChars = 200)`：
     - 檢查 `ui.*` 開頭之介面按鈕字串是否超過長度上限（避免 UI 爆框裁切）。
     - 檢查 `<color=...>`、`<b>`、`<i>` 等富文字標籤是否成對閉合。
3. **`SettingsModalView` 四語系切換按鈕 (`SettingsModalView.cs`)**：
   - 在設定視窗語言列擴充支援 `zh-TW`、`en`、`ja`、`zh-CN` 四種語言切換。

## 查核點（必須在測試中覆蓋）
- **M3-4-1**：`tools/LocalizationTool` 驗證 `zh-TW`、`en`、`ja`、`zh-CN` 四語系 100% 零錯誤通過。
- **M3-4-2**：`LocalizationValidator.ValidateUiLengthAndTags` 對正常四語系回傳 0 錯誤；故意注入超長 `ui.*` 字串或未閉合 `<b>` 標籤時精確回報錯誤（陽性對照）。
- **M3-4-3**：在 `SettingsModalView` 切換至 `ja` 與 `zh-CN` 時，`LobbyView` 導航文字即時切換為日文與簡體中文。

## 共同限制
- C# 9 以內：不使用 `record`、`init`、`file-scoped namespace`、`global using`。
- `Game.Domain` 與 `Game.Core` 嚴禁引用 `UnityEngine`。
- 註解使用繁體中文。
