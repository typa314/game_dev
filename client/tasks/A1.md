## 查核點（每一條至少要有 1 個測試，並在測試名稱或註解中標註編號）
- **A1-1**：`SplitMix64Random` 用同一個 seed 產生的 1,000 個 `NextDouble()` 完全相同；換成不同 seed 時，至少有 1 個值不同。
- **A1-2**：`NextDouble()` 的值都落在 [0,1)（抽 100,000 次）；`NextInt(n)` 的值都落在 [0,n)（n = 1、7、1000）；`NextInt(0)` 和 `NextInt(-1)` 丟出 `ArgumentOutOfRangeException`。
- **A1-3**：`Rarity.Rank` 的回傳值：N=0、R=1、SR=2、SSR=3；`Rarity.Rank("UR")` 丟出 `ArgumentException`。
- **A1-4**：`RatingPolicy`：`new RatingPolicy(Rating.R18, Rating.G).Effective == Rating.G`；`(G, R18)` 是 G；`(R18, R18)` 是 R18；`(R15, R18).Allows(Rating.R18) == false`；`Allows(Rating.R15) == true`。
- **A1-5**：EventBus 有兩個處理器 H1 和 H2；H1 收到事件 E1 時發佈 E2。預期的呼叫順序是 `H1:E1, H2:E1, H1:E2, H2:E2`（不會巢狀派送）。
- **A1-6**：處理器收到 E1 時丟出例外（例外會往外傳到 `Publish` 的呼叫端）。在丟出例外之前，另一個處理器已經發佈了 E2，E2 會留在佇列中。驗證：例外發生後再發佈 E3，處理器只會收到 E3，**不會**收到殘留的 E2。
- **A1-7**：處理器在派送途中取消訂閱自己，不會丟出例外；之後的事件不會再送到這個處理器。
- **A1-8**：`Result.Success().Ok == true`、`Result.Fail("x").Error == "x"`；`Result<int>.Success(5).Value == 5`。
- **A1-9**：`DomainEvent.With("k", 1.5)` 會以 InvariantCulture 轉成 `"1.5"`（測試時把 `CultureInfo.CurrentCulture` 暫時設為 `de-DE`，結束後在 finally 中還原）；`Get("missing")` 回傳 null。
