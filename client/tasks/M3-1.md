# 任務 M3-1：PortraitFactory 與 LobbyView / StoryPlayerView Live2D L1 正式串接

> **依據**：[`design/21_m3_content_live2d_and_dlc_plan.md`](../../design/21_m3_content_live2d_and_dlc_plan.md) Task M3-1、[`design/09_live2d.md`](../../design/09_live2d.md)、[`client/GEMINI_PROTOCOL.md`](../GEMINI_PROTOCOL.md)
> **目標**：實作 `PortraitFactory`，當 `SettingsState.UseLive2d == true` 且角色對應之 Live2D 模型資產存在時選用 `Live2DPortraitView`，否則無縫退回靜態立繪（`StaticPortraitView` / `DynamicPortraitController`）；並將其串接至 `LobbyView`（視線跟隨、部位點擊）與 `StoryPlayerView`（`<<expr>>` / `<<motion>>` 指令與口型同步）。

## 允許新增或修改的檔案（嚴禁修改範圍外檔案）
- `client/Assets/Game/Unity/Portrait/PortraitFactory.cs`（新增）
- `client/Assets/Game/Unity/Portrait/Live2DPortraitView.cs`
- `client/Assets/Game/Unity/UI/LobbyView.cs`
- `client/Assets/Game/Unity/UI/StoryPlayerView.cs`
- `client/Assets/Game/Tests/Live2DCubismIntegrationTests.cs`

## 實作細項與介面規格
1. **`PortraitFactory` (`PortraitFactory.cs`)**：
   - 提供 `CreateOrAttach(GameObject host, ResolvedPortrait portrait, bool useLive2d, Func<string, GameObject> prefabLoader = null)`：
     - 當 `useLive2d == true` 且 `portrait?.Art?.Live2d`（或指定映射模型）可載入有效 `CubismModel` Prefab 時，啟用並綁定 `Live2DPortraitView`。
     - 當 `useLive2d == false` 或無對應 Live2D Prefab 時，自動降級為靜態立繪（`StaticPortraitView`），絕不拋出例外。
2. **`LobbyView` 與 `StoryPlayerView` 串接**：
   - `LobbyView`：支援綁定 `Live2DPortraitView`，點擊角色觸發 `OnTouched("Head")` / `OnTouched("Body")`。
   - `StoryPlayerView`：當 `ShowCharacter`、`SetCharacterExpression`、`PlayCharacterMotion` 被呼叫時，同步驅動 `ActiveLive2DView.SetExpression(expr)`、`PlayMotion(motion)`，並在顯示台詞時依文字長度或語音驅動 `SetLipSync`。
