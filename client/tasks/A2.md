## 測試的寫法（A2-5 共用）
1. 每個測試都用 `MasterDataLoader.LoadFromDirectory(TestPaths.MasterDataDir())` 重新載入一份範例資料，**不要在測試之間共用**同一個 `MasterDatabase` 實例（測試會改動它）。
2. 建議寫一個 helper：先載入範例資料，確認 `MasterDataValidator.Validate` 回傳 0 個錯誤（前提檢查；萬一範例資料本身有錯，測試結果會失去意義），再套用一個改動，然後回傳新的錯誤清單。
3. 斷言時要**同時**檢查：
   - 有一筆錯誤以下表的「前綴」開頭（`StartsWith`，Ordinal 比較）；
   - 同一筆錯誤包含下表的「關鍵字」。
   不要斷言錯誤總數（一個改動可能連帶產生其他錯誤）。
4. 測試名稱或註解中要標註查核點編號，例如 `A2_5_03_PortraitStage_R18_IsRejected`。

## 查核點

### A2-3 載入器（`MasterDataLoaderTests.cs`）
- **A2-3a**：把 `data/master` 所有 `*.json` 複製到 `Path.Combine(Path.GetTempPath(), "game_a2_" + Guid.NewGuid().ToString("N"))`，將 `characters.json` 中**第一個** `"rarity"` 改成 `"rarty"`。`LoadFromDirectory` 要丟出 `System.IO.InvalidDataException`，而且 `Message` 包含 `characters.json`。
- **A2-3b**：同樣的暫存資料夾，但刪除 `config.json`：丟出 `FileNotFoundException`。
- **A2-3c**（對照組）：直接複製、不做修改的暫存資料夾可以正常載入，`Characters.Count` 等於 5。
- 暫存資料夾一律在 `finally` 中刪除（`Directory.Delete(path, true)`）。不可以寫入暫存資料夾以外的位置。

### A2-4 重複 ID（`MasterDataLoaderTests.cs`）
- **A2-4a**：呼叫 `MasterDatabase.Build`，傳入兩個 `Id = "dup"` 的 `CharacterDef`（其他參數傳 null）：丟出 `ArgumentException`（使用 `Assert.Catch<ArgumentException>`，子類別也可以）。
- **A2-4b**：同樣檢查兩個 `Id = "dup"` 的 `StageDef`。
- **A2-4c**（對照組）：所有參數都傳 null 時不會丟出例外，`Characters.Count == 0`，`Config` 不是 null。

### A2-6 錯誤訊息格式（`MasterDataValidatorTests.cs`）
- 把 A2-5 的 01～31 號改動**全部套用在同一份**範例資料上，執行一次 `Validate`。
- 每一筆錯誤都必須符合下列其中一個正規表示式（`System.Text.RegularExpressions.Regex`）：
  - 實體錯誤：`^(character|portraitStage|costume|scene|spot|stage|banner|encounter|encounter series|achievement) [^\s:]+: \S.*$`
  - 初始設定錯誤：`^config\.initial: \S.*$`
- 不符合時，斷言訊息要列出**所有**不符合的錯誤原文（方便企劃定位）。
- `config.growth`、`config.battle` 的錯誤訊息**不在本任務範圍**，不要為它們寫測試，也不要套用會觸發它們的改動。

## 限制
- namespace `Game.Tests`；NUnit 3（`using NUnit.Framework;`）。
- C# 9 以內：不使用 record、init、file-scoped namespace、global using、`new()` target-typed。
- 不依賴 UnityEngine。`MasterDataValidatorTests` 只能透過 `TestPaths.MasterDataDir()` 讀取範例資料；`MasterDataLoaderTests` 只能另外寫入自己建立的暫存資料夾。
- 斷言的期望值**依照本規格**撰寫，不要照抄程式目前的輸出。
- 不使用隨機數和目前時間。
- 註解使用繁體中文，風格和現有測試（`EncounterNoRecruitTests.cs`）一致。
