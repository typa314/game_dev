# 任務 M3-7：本機結構化當機與診斷日誌（LocalCrashLogger）與發行就緒自動稽核器（ReleaseReadinessAuditor）

> **依據**：[`design/21_m3_content_live2d_and_dlc_plan.md`](../../design/21_m3_content_live2d_and_dlc_plan.md) Task M3-7、[`design/16_roadmap.md`](../../design/16_roadmap.md) M4、[`client/GEMINI_PROTOCOL.md`](../GEMINI_PROTOCOL.md)
> **目標**：實作純本機、零外部傳輸之 `LocalCrashLogger`（只存本機 `logs/` 並具備檔案輪替上限），以及發行前綜合合規檢查器 `ReleaseReadinessAuditor`。

## 允許新增或修改的檔案（嚴禁修改範圍外檔案）
- `client/Assets/Game/Core/Diagnostics/LocalCrashLogger.cs`（新增）
- `client/Assets/Game/Core/Diagnostics/ReleaseReadinessAuditor.cs`（新增）
- `client/Assets/Game/Unity/GameBootstrap.cs`
- `client/Assets/Game/Tests/DiagnosticsAndReleaseAuditTests.cs`（新增）

## 實作細項與介面規格
1. **`LocalCrashLogger` (`LocalCrashLogger.cs`)**：
   - 純本機日誌寫入器：將未處理例外或嚴重錯誤格式化為 JSON/結構化文字寫入指定 `logDirectory`（如 `persistentDataPath/logs/`），絕不發送任何網路請求（符合專案機密不外洩原則）。
   - 支援檔案數量輪替（例如最多保留最近 `MaxLogFiles = 10` 份 log，超過時自動清理最舊檔案）。
2. **`ReleaseReadinessAuditor` (`ReleaseReadinessAuditor.cs`)**：
   - 綜合檢查：
     1. 主資料驗證（`MasterDataValidator` 0 錯誤）。
     2. 多語系完整性與 UI 長度驗證（`LocalizationValidator` 對 `zh-TW`, `en`, `ja`, `zh-CN` 0 錯誤）。
     3. 本體 Catalog R18 零洩漏（`AddressablesCatalogAuditor` 0 錯誤）。
     4. 發行模式（`strictReleaseMode: true`）下檢查 `asset_manifest.csv` 是否仍有 `placeholder` 狀態資產。

## 查核點（必須在測試中覆蓋）
- **M3-7-1**：連續寫入 15 筆當機日誌（設定 `MaxLogFiles = 10`）後，目錄下精確保留最新 10 份日誌，且內容包含例外訊息與堆疊。
- **M3-7-2**：`ReleaseReadinessAuditor` 在開發模式下通過檢查；在 `strictReleaseMode: true` 且含有 `placeholder` 資產或缺失翻譯時，精確攔截並列出阻擋發行原因（陽性對照）。

## 共同限制
- C# 9 以內：不使用 `record`、`init`、`file-scoped namespace`、`global using`。
- `Game.Domain` 與 `Game.Core` 嚴禁引用 `UnityEngine`。
- 註解使用繁體中文。

## 驗證報告與成果 (M3-7 已完成)
- **M3-7-1 (`LocalCrashLogger` 檔案輪替與結構化日誌)**：
  - 新增 `LocalCrashLogger.cs`：純本機檔案寫入，將未處理異常結構化格式化為包含時間戳、例外型別、錯誤訊息、自訂 context 與完整堆疊追蹤（Stack Trace）之記錄檔。
  - 嚴格本機運作，絕無任何外部網路傳輸，符合機密與離線規範。
  - 連續寫入 15 筆日誌（設定 `MaxLogFiles = 10`），目錄中精確保留最新 10 份日誌（`fileCount == 10`），且最舊的 5 筆日誌（#00～#04）全數由舊至新自動清理淘汰，最新記錄 #14 完整保留且堆疊結構正確。
- **M3-7-2 (`ReleaseReadinessAuditor` 發行就緒綜合審計與三重複合陽性對照)**：
  - 新增 `ReleaseReadinessAuditor.cs`：整合 `MasterDataValidator`（0 錯誤）、`LocalizationValidator`（四大語系完整性與 UI 長度合規）、`AddressablesCatalogAuditor`（本體 Catalog R18 零洩漏）與發行模式佔位符檢查。
  - 開發模式（`strictReleaseMode: false`）：全專案主資料、四語系與本體資產通過審計（`IsPassed == true`，0 錯誤，掃描 9 張 Master 表格、4 大語系）。
  - 陽性對照 A（發行模式阻擋 placeholder）：在暫存 manifest 中注入 `placeholder` 狀態資產，開啟 `strictReleaseMode: true` 執行，精確攔截並回報 `ERR_PLACEHOLDER_IN_RELEASE`。
  - 陽性對照 B（缺失語系攔截）：建立刻意缺漏 `en`, `ja`, `zh-CN` 語系之目錄，審計立即攔截並回報 `ERR_LOCALE_MISSING`。
  - 陽性對照 C（Null Master 攔截）：傳入 null 主資料立即回報 `ERR_MASTER_NULL` 並中斷。
- **全域當機捕獲整合 (`GameBootstrap.cs`)**：
  - 在 `GameBootstrap.Awake()` 中透過 `Application.logMessageReceivedThreaded` 註冊全域當機監聽，當捕捉到 `LogType.Exception` 或 `LogType.Assert` 時，自動調用 `LocalCrashLogger` 將結構化日誌落地至本機 `persistentDataPath/logs/`。
- **測試結果**：
  - .NET 8 CLI (`Game.DotnetTests.dll`): 2/2 通過 (`DiagnosticsAndReleaseAuditTests`)。
  - Unity 6000.6.5f1 EditMode (`Game.Tests.DiagnosticsAndReleaseAuditTests`): 2/2 全數通過。
